DATA INPUT
These files contain data extracted from the supplementary materials from Tursic et al. (2020) and Kohl et al. (2020) that have been recoded to function with our analysis script. The “originalSummary” files, contain the data from Table 3 of Tursic et al. and Table 5 of Kohl et al. Column headers in the data files: n = sample size, ng = number of groups, nm = number of measurements, type (2 = interaction, 1 = between groups).
o	fMRInf_behaviour.csv
o	fMRInf_regulation.csv
o	fMRInf_originalSummary.csv
o	fNIRSnf_behaviour.csv
o	fNIRSnf_regulation.csv
o	fNIRSnf_originalSummary.csv

DATA OUTPUT
These files contain all the recalculated power and sensitivity analyses for each study included in the reviews.
o	fMRInf_recalculatedBehaviour.csv
o	fMRInf_recalculatedRegulation.csv
o	fNIRSnf_recalculatedBehaviour.csv
o	fNIRSnf_recalculatedRegulation.csv

# Instructions

## The computational environment (Docker image)

This capsule has been published and its environment has been archived and made available on Code Ocean's Docker registry:
`registry.codeocean.com/published/a8bd4c5f-7e2a-4184-99b1-a15f16a372dd:v1`

## Running the capsule to reproduce the results

In your terminal, navigate to the folder where you've extracted the capsule and execute the following command, adjusting parameters as needed:
```shell
docker run --platform linux/amd64 --rm \
  --workdir /code \
  --volume "$PWD/data":/data \
  --volume "$PWD/code":/code \
  --volume "$PWD/results":/results \
  registry.codeocean.com/published/a8bd4c5f-7e2a-4184-99b1-a15f16a372dd:v1 bash run.sh
```
