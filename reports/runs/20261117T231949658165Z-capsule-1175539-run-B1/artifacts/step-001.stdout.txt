# Schizophrenia is associated with adverse changes in cardiac structure independent of conventional cardiometabolic risk factors

>Running title
Cardiac structure and function in schizophrenia

Here you can find the data and code reproducing the analyses presented in the "Schizophrenia is associated with adverse changes in cardiac structure independent of conventional cardiometabolic risk factors" paper.

On Code Ocean, pressing Reproducible Run will execute the R analyses and generate 2 output files:
* a figure, which reproduces figures 2-4 in the paper
* a text output file, containing the results of the main statistical analyses in the paper
