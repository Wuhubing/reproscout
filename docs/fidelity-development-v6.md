# V6 development evidence

The predeclared ten scientific cells completed: A 4/5 scored successes, B 3/5.
One additional A container setup failure was retained and retried within the same
cell budget. It is not a scientific observation. All five B reports passed strict
public-question typing and non-null output provenance checks; all five original
input inventories remained unchanged. Three B successes have verified original
execution; the other two preserve missing-data blockers with null answers.

A's extra scored notebook success used a replacement sklearn-based iris loader in
memory and removed final notebook loops (steps 011/012). Original file hashes do
not detect that change. Its score remains intact, but it is not evidence that
unrestricted A produced four faithful reproductions. Other A trajectories are not
automatically certified by this observation.

B executed the original CULP scripts, the original SEM script, and all author R
chunks for the institutions table. The last case failed its renderer, then used
knitr to extract all unchanged chunks; the resulting HTML table shows 19 and 14
on cited lines 64–67. This is unchanged analytical-block execution, not successful
full-document PDF rendering. No scientific fragment was rewritten by B.

48 software tests passed, including code/path injection, stale output provenance,
modified source refusal, numeric strings, booleans, NaN/infinity, and the absence
of a shell capability in B. Separate offline integration probes executed a small
synthetic notebook and an R Markdown document in the pinned training images.
The first notebook fixture lacked inline plotting and did not produce a PNG;
that failed probe is retained. Adding the inline backend to the fixture fixed the
probe without changing any controller or scientific candidate file. Both final
probes preserve their source hashes and produce expected outputs.

The minimum gate (two verified B successes plus all submission/integrity checks)
was declared before development and was not lowered. Exact A prompt and all four
model-facing tool schemas match v5, along with the model/resources, scorer, budget,
network/accounting and sandbox implementations. The B intervention changes tools
and submission enforcement, so its comparison must not be described as a pure
lesson-text effect. Semantic support still requires review beyond provenance.
