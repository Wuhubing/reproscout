## What the demonstration establishes

A prepared scikit-learn diabetes example can be imported into the authenticated
workspace. The retained acceptance run executed original code, produced three
candidate answers, and preserved evidence and an input-integrity audit. The
walkthrough inspects MSE 2548.07 in the actual stdout, shows assistant-attributed
reviews and review history, and exports a report with working offline citations.
The original run used five model calls, took 20.4015 seconds, and had an estimated
model cost of $0.00422805. The separate GitHub Actions acceptance record verifies
the fixed Docker/controller integration.

These are bounded product acceptance results, not proof of paper-wide reproduction,
independent human validation, or a consistent benefit from lessons. Historical
A/B studies, earlier versions, failed attempts and source evidence are preserved.

## Scope of this delivery

This first delivery is the working development-host application, its public
read-only evidence archive, source repository, documentation and narrated video.
The authenticated execution app supports prepared-project upload, execution,
evidence review and export on the development host. The GitHub Pages website
cannot execute uploaded projects. Durable public execution hosting and independent
researcher evaluation remain future work, not claims of this delivery.

No always-on local server is needed for teachers to watch the video, browse the
public evidence, or inspect the repository. Do not delete the private recordings,
credentials, account state or retained raw evidence; they remain outside Git.
